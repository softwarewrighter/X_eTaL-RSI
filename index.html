X_eTaL-RSI

Recursive self-improvement in X_eTaL, the eXperimental Extensible Typed Array Language: small, deterministic experiments in which a system improves the harness it runs in, and then the procedure by which it improves it, without changing a model's weights. Each experiment is a simulation with a control; the live pages run X_eTaL in your browser (WebAssembly).
